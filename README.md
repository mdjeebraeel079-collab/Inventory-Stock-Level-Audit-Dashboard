# Inventory Stock Level Audit Dashboard

## Project Overview
This project analyzes inventory stock levels across multiple warehouses using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis

## Key Metrics
- Total Inventory Value
- Total Unique Products
- Total Warehouses
- Low Stock Products

## Dashboard Insights
- Inventory Value by Category
- Inventory Value by Warehouse
- Stock Status Distribution
- Top 10 Products by Inventory Value

## Business Benefits
- Identify low stock products
- Monitor warehouse inventory
- Improve stock management
- Support inventory planning
